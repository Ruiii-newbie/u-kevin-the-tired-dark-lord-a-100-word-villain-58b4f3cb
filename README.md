A 100-word monologue for a fantasy villain who is secretly just very tired.
Malachar, Tithe-Keeper of the nine valleys, signs tithes in triplicate,
loses stablemasters, raises the dead on third Tuesdays, and leaves the gate
unlocked for the hero — because some villains want the world, and he wants
a nap and a quiet Tuesday.

## Run

```sh
python3 main.py   # writes the monologue to /output/entry.txt
```
